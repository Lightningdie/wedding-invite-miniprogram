# 云数据库开通说明

祝福留言、宾客名单、婚礼配置已支持「本地持久化 + 云数据库双写」。

## 当前行为

- **未开通云开发**：数据写入手机本地存储（`wx.setStorage`），关闭小程序再打开仍然存在，但换手机/清除缓存会丢失。
- **已开通云开发**：本地保存的同时写入云集合，后台与邀请函两端都能读到，可长期保留。

## 开通步骤

1. 微信开发者工具 → 顶部「云开发」→ 开通并创建环境  
2. 复制环境 ID，填入 `app.js` 的 `globalData.cloudEnv`  
3. 在云开发控制台创建 3 个集合（权限建议：所有用户可读，仅创建者可写；或按需「所有用户可读写」方便宾客提交祝福）：

| 集合名 | 用途 | 说明 |
|--------|------|------|
| `wedding_config` | 婚礼信息 | 文档 ID 固定为 `main` |
| `blessings` | 祝福留言 | 自动生成 `_id` |
| `guests` | 宾客名单 | 自动生成 `_id` |

4. 重新编译小程序，后台首页应显示「云数据库已连接」

## 字段示例

**blessings**

```json
{
  "name": "张三",
  "count": "2",
  "message": "新婚快乐",
  "time": "9月29日 08:30",
  "createdAt": "<serverDate>"
}
```

**guests**

```json
{
  "name": "张三",
  "count": 2,
  "status": "confirmed",
  "message": "新婚快乐",
  "time": "9月29日 08:30",
  "createdAt": "<serverDate>"
}
```
