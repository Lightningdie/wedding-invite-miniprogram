# 婚礼邀请函微信小程序

刘浩宇 & 张婧怡 · 2026.9.29

## 邀请函（8 页横向翻书）

1. 封面倒计时  
2. 诚挚邀请  
3. 婚礼信息  
4. **甜蜜相册**（专页）  
5. **我们的故事**（专页）  
6. 地点导航  
7. 婚礼流程  
8. 祝福留言  

- 每 18 秒自动翻页，手动翻页后重新计时  
- 关闭音乐 → 同时取消自动翻页；再次开音乐可恢复  
- 横向慢速翻书（约 1.2s）+ 透明度渐变  
- 组件从左/右/上/下缓入，由虚到实  

## 数据持久化

祝福、名单、配置会写入本地；开通云开发后同步到云数据库。详见 `cloud/README.md`。

## 后台

长按邀请函右上角音乐按钮 → 首页 / 编辑 / 名单管理  

## 音乐

将 mp3 放到 `assets/music/bgm.mp3`
